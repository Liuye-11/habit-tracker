# The day you insist · 习惯打卡

一个简单好用的习惯打卡网页，已部署到公网。

## 🌐 在线地址

**https://liuye-11.github.io/habit-tracker/**

## ✨ 功能

- 🌤️ **天气背景（苹果天气风格）**：背景随当天天气自动变化（晴/多云/阴/雨/雪/雷雨/雾/夜晚），右上角可手动切换；未联网时按时间段显示
- 💧 **常用模板**：24 个常用习惯一键添加（喝水💧、运动🏃、读书📚、早睡😴…），图标自动配好，不用打字
- 🎨 **自定义添加**：40 个常用 emoji 任选，还支持自由输入任意 emoji/符号
- ✒️ **高级字体风格**：衬线字体，杂志质感
- ✅ 每天完成一项点一下打勾，顶部实时显示「今日完成 X / Y 项」+ 进度条
- 🔥 每个习惯显示「连续打卡 X 天」小徽章
- 🗓️ 按日期自动记录，每天自动重新开始
- 📱 手机 / 电脑自适应

## 本地使用

直接双击打开 `index.html` 即可（推荐 Chrome / Edge）。

## 部署 / 更新

仓库：https://github.com/Liuye-11/habit-tracker

改好 `index.html` 后推送到 main 分支，GitHub Pages 自动发布，几分钟后生效。

## 数据说明

记录保存在浏览器本地（localStorage）。换浏览器、清空浏览器数据、或换设备后，记录不跟随。天气数据来自 wttr.in（IP 定位），未联网时自动按时间段显示背景。
