# The day you insist · 习惯打卡

一个简单好用的本地习惯打卡网页，可一键部署到公网。

## 功能

- 🌗 **双主题**：暖色调 / 暗色调，右上角一键切换，自动记住你的选择
- ➕ **独立添加按钮**：主页只展示「今日习惯」，点右下角「＋」弹出添加窗口
- 👤 只显示你自己添加的习惯，无任何演示数据
- ✅ 每天完成一项就点一下圆圈打勾，再点可取消
- 📊 顶部实时显示「今日完成 X / Y 项」+ 进度条，全部完成有 🎉 庆祝
- 🗓️ 按日期自动记录，第二天自动重新开始
- 🔥 每个习惯显示「连续打卡 X 天」小徽章
- 📱 手机 / 电脑自适应

## 本地使用

直接双击打开 `index.html` 即可（推荐 Chrome / Edge）。

## 部署到公网

见 `部署说明.md`，推荐 GitHub Pages（免费、永久）。

## 数据说明

记录保存在浏览器本地（localStorage）。注意：换浏览器、清空浏览器数据、或换域名后，记录不跟随。同一个网址 + 同一个浏览器，数据才会一直保留。
